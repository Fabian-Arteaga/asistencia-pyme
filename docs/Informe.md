## ¿Cómo elaboré la aplicación?

Para empezar el proyecto primero revisé los requerimientos para tener claro qué debía hacer la aplicación. Después diseñé la base de datos y preparé la documentación, ya que quería tener una guía antes de comenzar a programar y evitar hacer cambios grandes más adelante.

Con esa base lista, empecé a desarrollar el backend utilizando ASP.NET Core Web API y PostgreSQL. 

---

# Dificultades y desafíos encontrados

Uno de los retos que encontré fue entender cómo organizar correctamente el proyecto utilizando Clean Architecture y CQRS. Al principio me costó identificar dónde debía ir cada clase y cuál era la responsabilidad de cada capa.

También tuve algunas dificultades al implementar la autenticación con JWT, principalmente con la generación del token, la protección de los endpoints y la configuración de Swagger para poder probar los endpoints que requerían autenticación.

Otro desafío fue el diseño de la base de datos.

---

# ¿Qué aprendí?

Este proyecto me ayudó a comprender mucho mejor cómo se desarrolla una API desde cero

Aprendí a trabajar con Clean Architecture y CQRS.

Otro aprendizaje importante fue implementar autenticación con JWT y utilizar PBKDF2 para almacenar de forma segura las contraseñas y los PIN.

Además, mejoré mi forma de trabajar con Git y GitHub, utilizando ramas y una mejor organización de los commits durante el desarrollo.

Algo que también aprendí fue la importancia de la documentación.
